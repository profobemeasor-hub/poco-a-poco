# Poco a Poco v8 — Adaptive Offline Coach

v8 keeps the app fully offline-first and adds an adaptive conversation engine.

## What's new
- 12 multi-turn everyday conversations
- 3-turn sessions instead of one-shot prompts
- randomized prompts so repeats are less predictable
- "Surprise me" practice
- recommendation engine based on low confidence and previous scores
- local weak-word / useful-phrase memory
- local recurring grammar-pattern memory
- automatic recycling of missed language
- voice-first input where Safari supports Web Speech Recognition
- Spanish text-to-speech
- session scoring
- no OpenAI API, Cloudflare Worker, PIN, or paid service required

All adaptive memory remains in browser localStorage.
