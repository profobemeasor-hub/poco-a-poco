# Poco a Poco v13 — Partner & Tutor Mode

v13 adds structured two-person practice without adding any paid backend.

New:
- 6 partner roleplay sessions
- one-device role handoff
- learner/partner role labels
- peer scoring
- peer feedback shortcuts
- 15, 30 and 45 minute tutor plans
- tutor notes
- local partner-session history
- session average tracking
- no accounts, server or paid API required

This is local co-op, not internet multiplayer.
