# Poco a Poco v14.1 — Berlitz Reinforcement

Adds an optional Berlitz Español 1 Level 1 reinforcement track inside Learn.

- Crash Course remains the default beginner path.
- Berlitz L1 maps 40 units into four stages.
- Each unit shows its communication goal, language focus, and matching Poco a Poco module.
- Selected units include original reinforcement examples and text-to-speech.
- Berlitz PDFs and audio are NOT bundled into the app, which keeps the GitHub deployment clean and avoids redistributing licensed course files.
