# Poco a Poco v5 — Live Guatemala

Version 5 changes the primary learning model from workplace vocabulary to real-life conversational confidence.

## New in v5
- Living Journey with 10 chapters, everyday life first
- Real-world missions that happen outside the app
- Recurring roleplay characters
- Voice or typed roleplay answers
- Communication scoring + natural model replies
- Confidence map by life situation
- Daily reflection
- Offline-first PWA remains enabled

## Important
The roleplay engine is intentionally local/offline. It does not expose an OpenAI API key in browser code. A secure AI backend can be connected later.
