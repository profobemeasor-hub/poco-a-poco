# Poco a Poco v10 — Personas

v10 adds recurring real-life characters to the offline practice experience.

## New
- 10 recurring personas
- different speaking styles and difficulty levels
- persona profiles with habits and opening lines
- dedicated scene selection per persona
- multi-turn roleplay with voice or typing
- communication scoring
- natural model responses
- memory integration through the existing local adaptive coach
- no OpenAI API
- no Cloudflare Worker
- no paid service

Personas include:
María (café owner), José (Uber driver), Sofía (friend), Miguel (security),
Dra. Ana (doctor), Diego (bank adviser), Lucía (restaurant server),
Carlos (market vendor), Laura (property manager), and an immigration officer.
